## О проекте

Учебный сайт магазина электроники. На нём можно посмотреть каталог ноутбуков, смартфонов и наушников, открыть страницы товаров, ознакомиться с доставкой и заполнить демонстрационные формы заявки и обращения.

**GitHub Pages:** [https://dattebayo-ek.github.io/kr3-responsive-shop/](https://dattebayo-ek.github.io/kr3-responsive-shop/)  
Это адрес по имени репозитория; проверьте, что публикация включена в настройках GitHub Pages.

## Страницы

- `index.html` — главная, подборка популярных моделей, советы по выбору и преимущества магазина.
- `catalog.html` — категории, карточки товаров, фильтры и сравнение характеристик.
- `product.html` и `product-*.html` — девять страниц моделей с изображениями и таблицами параметров.
- `cart.html` — демонстрационный экран корзины и условий покупки.
- `order.html` — форма заявки и примеры предыдущих заказов.
- `delivery.html` — способы и этапы получения заказа.
- `contacts.html` — контакты и форма обращения по заказу.

## Что сделано

- Добавлен отдельный файл `css/responsive.css`; он подключён после `css/style.css` на всех HTML-страницах.
- У всех страниц есть `meta viewport`. Базовая раскладка в адаптивном файле рассчитана на узкий экран, а медиазапросы от 768 и 1024 пикселей добавляют более широкие сетки.
- Для навигации, каталога, карточек, блоков главной, форм и других разделов применены Flexbox и CSS Grid.
- Страница товара и изображения подстраиваются под ширину карточки. Для ряда изображений заданы варианты `srcset` и `sizes`, а в стилях — ограничение ширины `img` и `video`.
- Таблицы характеристик прокручиваются внутри своего контейнера; это не расширяет страницу целиком. Лента популярных товаров также прокручивается отдельно и поддерживает переход назад и вперёд без JavaScript.
- Формы переходят в одну колонку на узком экране; для текстовых полей задана фиксированная высота.
- В `css/responsive.css` предусмотрено уменьшение анимации при `prefers-reduced-motion`.

## Доступность

- На страницах есть ссылка для перехода к основному содержимому и видимое состояние `:focus-visible`.
- Для навигации используются семантические области; у каждой страницы один `h1`.
- У изображений есть `alt`, а поля форм связаны с подписями `label`.
- Подписи таблиц сохранены для скринридеров, но скрыты визуально.

## Проверка адаптивности

В локальном браузере проверены все 15 HTML-страниц на ширинах 320, 360, 430, 768, 1024, 1440 и 1920 пикселей. На этих размерах ширина документа не превышает ширину экрана; горизонтальная прокрутка остаётся только у таблиц и ленты товаров. Дополнительно вручную осмотрена главная страница на телефоне.

Проверка проводилась в одном браузере и не заменяет осмотр на реальных телефонах или проверку в других браузерах.

## Запуск локально

Откройте папку проекта в терминале и запустите простой сервер:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Для проверки остановите сервер сочетанием `Ctrl+C`.
